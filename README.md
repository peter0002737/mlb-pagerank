# MLB PageRank

用 PageRank 為 MLB 球隊排名，並以季後賽與逐場比賽回測預測能力。

## 檔案

| 檔案 | 用途 |
|---|---|
| `mlb_pagerank.m` | 主程式（MATLAB，不需任何 Toolbox）。抓賽程 → 建「輸家 → 贏家」加權有向圖 → 阻尼矩陣 D → Google 矩陣 G = D·P + (I−D)·E → 冪迭代求 PageRank → 排名、敏感度分析、季後賽回測與奪冠機率 |
| `damping_backtest.py` | 阻尼參數回測（Python + numpy）。用 2021–2025 球季逐日滾動預測每一場例行賽，找出讓預測最準的阻尼設定 |

## 模型

- **邊權重**：每勝 1，主客場做反機率加權（主場勝 × 1/(2h)、客場勝 × 1/(2(1−h))，h = 全聯盟主場勝率）。
- **阻尼矩陣**：每隊一個阻尼值 d_i = L_i / (L_i + c·mean(L))，L_i 為輸球場數，c 為 `DAMP_SCALE`。
- **單場勝率**：p = PR(A) / (PR(A) + PR(B))。

## 阻尼參數回測結果（2021–2025，10,607 場）

| 設定 | 命中率 | log loss |
|---|---|---|
| c = 0.2 | 55.63% | **0.68392**（最低） |
| c = 1（預設） | 55.65% | 0.68580 |
| 單一 α = 0.85 | 55.58% | 0.68416 |
| 勝率較高者勝（log5） | 55.79% | 0.69055 |

- 命中率在各 c 之間差異落在雜訊範圍內，調阻尼無法提高猜對率。
- 以 log loss 衡量機率準確度，c ≈ 0.2 最好，且五個球季的最佳值都落在 0.05–0.4。

## 執行

MATLAB：

```matlab
mlb_pagerank
```

Python 回測：

```bash
pip install numpy
python3 damping_backtest.py
```

兩支程式第一次執行時會從 MLB Stats API 下載賽程並存成 CSV 快取，之後直接讀快取。
